Your layouts

Use your layout in BAR · Noryon’s Layout Planner

Download Layout Planner by Noryon · Creator’s project

  1. Install LayoutPlanner.lua in your BAR data folder’s LuaUI/Widgets folder and enable Layout Planner in game.
  2. Choose an unused slot (1–20), click Export for BAR, and put the downloaded layout_N.txt in the same LuaUI/Widgets folder. This replaces that slot’s saved layout.
  3. In the widget click Load for your slot, move the preview to your base, then click to place it. Click Render to draw the guide.

Building sizes and relative spacing are preserved. Position the layout in game; the widget draws guides rather than building units automatically. Freehand lines export to BAR; text labels are saved in website layouts and images. Used with Noryon’s permission, with original author credit retained.

Build footprints, not model outlines. Overlapping drawings are allowed; terrain, space and in-game build restrictions still matter. Weapon circles are shown only where the configured range is verified. Layouts save in this browser; export a file to share them.
