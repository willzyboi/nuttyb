Your layouts

Use your layout in BAR · Noryon’s Layout Planner

Download Layout Planner by Noryon · Creator’s project

  1. In the BAR launcher, open the game data directory. Open LuaUI → Widgets (create these folders if missing). Download the updated LayoutPlanner.lua above into that folder, replacing your older copy, then enable Layout Planner in the in-game widget list.
  2. Choose an unused slot (1–20), click Export for BAR, and put the downloaded layout_N.txt in the same LuaUI/Widgets folder. For example slot 20 must be named layout_20.txt, not layout_20 (1).txt or layout_20.txt.txt. Slots run from layout_1.txt through layout_20.txt. Both the widget and these TXT files go directly inside LuaUI/Widgets, not Downloads. This replaces that slot’s saved layout. Copy layout text is an alternative: paste into Notepad and Save As with All files selected, using the exact layout_N.txt name.
  3. In the widget click Load for your slot, move the preview to your base, then click to place it. Click Render to draw the guide.

Building sizes and relative spacing are preserved. Position the layout in game; the widget draws guides rather than building units automatically. The TXT file also keeps editable building names, drawn lines and labels for re-importing here. This updated widget draws outlines, building names and text labels. Untick Show building names in BAR to omit automatic names. Used with Noryon’s permission, with original author credit retained.

Build footprints, not model outlines. Overlapping drawings are allowed; terrain, space and in-game build restrictions still matter. Weapon circles are shown only where the configured range is verified. Layouts save in this browser; export a file to share them.
