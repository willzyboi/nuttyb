How to use your layout in BAR
  1. Put gui_willboizy_layout_loader.lua in your BAR data folder under LuaUI/Widgets. Disable the old Layout Planner and enable Willboizy Layout Loader.
  2. Choose a BAR slot above and click Download layout for BAR. Put that layout_N.txt file in the same Widgets folder, keeping its exact filename.
  3. In game, select the matching layout from the dropdown. Click the map to position it, then press Render. R rotates, I mirrors and right-click cancels placement.
