Layout Planner by Noryon — Hive Reminder edition

Original project: https://github.com/noryon/BARLayoutPlanner
Original author: Noryon. License: MIT. Hive reminder added for Willboizy.

Put LayoutPlanner.lua and layout_1.txt through layout_20.txt in BAR's LuaUI/Widgets folder. Disable Willboizy Layout Loader and enable Layout Planner.

Use Noryon's existing Load buttons, place the preview, then Render. Original drawing, editing, rotation, placement and line rendering are retained.

Hive Push Reminder sends: Please do not push the hives with units or launchers before they spawn!!

Building names and imported text labels never create map pings in this edition. Existing map marks must be erased separately.
